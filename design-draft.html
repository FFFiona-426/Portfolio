01

风格提炼：从参考站继承什么，改造什么

参考项目最打动人的是「戏剧感 + 手作感」：拉开的红丝绒幕布、金色时钟、烛光微粒，配上红白格纹纸卡、木夹拍立得、圆润手写字体、打字机情书。这些全部保留；改造的是结构——把「密码 → 3 个礼盒」的线性展示，换成「一张可自由探索的星图 + 5 个可计分的小游戏」。

标志性元素清单

  • 白边拍立得 + 小木夹 + 手写花体说明，轻微摇摆物理感
  • 金色描边与光晕：时钟、星星、进度徽章统一 2~3px 金边 + 柔光
  • 彩色星星贴纸（青 / 橙 / 黄 / 玫红 / 紫 / 蓝）作为点缀与计分单位
  • 环境粒子：烛光微粒、飘落玫瑰花瓣、彩纸屑三层，低透明度不抢主体
  • 纸张质感：撕边、圆角、投影、2~6° 随机倾角，禁止纯平直角卡片
  • 弹性动效：cubic-bezier(.34,1.56,.64,1)，所有卡片有轻微悬浮/摇摆
改造原则：参考站是「看」的礼物，这版是「玩」的礼物。每一屏都必须有明确的操作、即时反馈、可见进度和奖励；任何一关都能单独重玩刷分，不因失败卡住流程。
02

玩法流程：集齐 7 颗愿望星

叙事钩子：生日蛋糕上的 7 颗愿望星被夜风吹散，散落在「生日星球」的 5 个游乐摊位。每通一关得 1~3 颗星（按表现评级），集满 7 颗点亮终章生日信。关卡可任意顺序进入，避免线性卡关。

不会卡住

无失败惩罚、无强制顺序、无次数限制；任意关卡首次通关保底 1 星，7 星目标可通过重复刷分达成。密码错误给提示而非阻断。

有得追

星级评级 + 最佳纪录 + 成就徽章 + 祝福券图鉴 + 纪念卡，四套收集目标叠加，localStorage 存档，隔天回来进度还在。

有惊喜

随机文案池、稀有扭蛋、隐藏彩蛋、麦克风吹气、剧情表情反应，重复进入也不会看到完全一样的一屏。

05

交互状态与动效规范

统一的反馈语言，让 5 个小游戏看起来像同一个世界里的东西。

默认卡片 2~6° 倾角、柔和投影、呼吸式浮动 3~6s
悬停 / 聚焦上浮 6px、放大 1.04、金色描边亮起（触控端跳过）
按下缩放 .96 + 轻微旋转，120ms 回弹
成功粒子爆裂 + 分数浮字 + 星星飞向右上进度条
失误左右轻摇 2 次 + 柔和红闪，不中断、不扣分

键盘 / 无障碍

  • 0-9 密码输入　Enter 确认 / 一次吹灭
  • Space 全吹蜡烛　← → 翻牌选择 / 照片浏览
  • Esc 返回星图 / 关闭弹窗　M 静音
  • 触控热区 ≥ 44px；所有交互可纯键盘完成；prefers-reduced-motion 关闭粒子与摇摆；焦点可见描边。

动效与音效 Token

  • 弹性缓动 cubic-bezier(.34,1.56,.64,1)，入场 320ms、反馈 160ms、转场 600ms
  • 粒子三层：烛光微粒 12 / 花瓣 8 / 彩纸 60，移动端减半
  • 音效由 Web Audio 实时合成（点击、命中、成功、翻牌），不依赖外部音频文件，默认静音需用户手势后开启
06

响应式与技术实现

布局适配

桌面 ≥1024：中心舞台 + 左右留白，粒子全量。平板 768~1024：缩小画布，星图节点改 3+2 换行。手机 <768：单列竖屏、底部拇指区放主按钮、HUD 收成一行、禁止横向滚动、100dvh 适配刘海屏。

技术选型

与参考站一致：纯 HTML + CSS + 原生 JS，零框架零构建。图形用内联 SVG / CSS 渐变，Canvas 仅用于彩纸、签名与纪念卡导出；进度存 localStorage；字体走 Google Fonts 并有系统字体兜底；单文件即可部署。

文件结构（建议）

index.html
style.css（含 :root 设计变量）
script.js（状态机 + 5 个关卡模块）
assets/ 照片 · 表情图
config.js（昵称/密码/文案/照片/日期 全部集中配置）

交付分期建议

第一轮 · 可玩骨架（MVP）
开幕倒计时与幕布 → 星图 HUB → 关卡 ①②③ → 星级/进度/localStorage → 终章打字机情书。此时整条链路已可完整通关，可先在真机上跑一遍节奏。

第二轮 · 可玩性加厚
关卡 ④ 扭蛋、⑤ 拼图签名、成就徽章、3 处彩蛋、纪念卡导出、Web Audio 音效与音乐开关。

第三轮 · 个性化与打磨
替换真实照片与文案、生日主角昵称、特殊日期、表情素材；移动端逐屏走查、动效降级、性能与首屏加载优化；最后发布成可分享链接。

07

需要你确认的 6 件事

  • 主角昵称与生日日期：用于标题、密码提示与纪念卡落款
  • 4 位开场密码：生日年份 / 纪念日，或干脆去掉密码直接拆邀请函
  • 照片素材：翻牌与拍立得共需 6~10 张，没准备时先用风格化占位图
  • 情书文案：终章打字机内容，可分 3~4 段
  • 风格取舍：是否保留参考站的蜡笔小新元素？这版草稿用了通用的星星/蛋糕/拍立得，规避版权形象
  • 范围与交付：先做 MVP 三关还是五关全上；是否需要背景音乐、分享链接、下载纪念卡
  • 玩法偏好：偏「轻松治愈」还是「有挑战计分」？可调整计时压力与评级门槛
  • 验证方式：按你习惯的分轮迭代，每轮改动后我会给可预览链接，你在真机上过一遍再提下一轮
